# Ideas

The scratch pad. Nothing here is decided. If an idea grows up it moves to [[Roadmap]]; if it dies it gets struck through and left as a warning.

## Editor

- Split view, source on the left and rendered on the right, with scroll lock
- A "focus" mode that hides the tree and widens the note
- Typewriter scrolling: keep the cursor line in the middle
- ~~Rich text editing~~ No. The file is the interface.

## Tree

- Pin a note to the top of the tree
- Colour a folder from a fixed palette in the tokens file
- Collapse everything with one key
- Show a count of notes per folder on hover

## Links

- Hover a `[[link]]` to see the first paragraph of the target
- Warn before renaming a note that other notes link to
- An "unlinked mentions" list: notes that say "Week 39" in plain text but do not link to [[Week 39]]
- Let `[[Journal/2026/September]]` work as well as `[[September]]` when names collide

## Odd ones

- A tiny command palette that runs shell snippets from [[Code samples]] against the current note
- Render `> [!quote]` callouts with the source name pulled from the next line
- A "random note" button for rereading old journal pages
- A word count in the status bar, and a reading time next to it
