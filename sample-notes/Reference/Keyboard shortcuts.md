# Keyboard shortcuts

Every shortcut in the app on one page. The rule from [[Plexar Notes]]: every action has a key, and no shortcut uses more than two modifiers.

## Navigation

| Keys | Action |
|------|--------|
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Quick switcher (coming, see [[Roadmap]]) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Focus the file tree |
| <kbd>Alt</kbd>+<kbd>Left</kbd> | Back to the previous note |
| <kbd>Alt</kbd>+<kbd>Right</kbd> | Forward again |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open folder |

## Notes

| Keys | Action |
|------|--------|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New note in the current folder |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Toggle edit and preview |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save now |
| <kbd>F2</kbd> | Rename the selected note or folder |
| <kbd>Delete</kbd> | Move the selected file to the system bin |

## Tree

| Keys | Action |
|------|--------|
| <kbd>Up</kbd> / <kbd>Down</kbd> | Move the selection |
| <kbd>Left</kbd> / <kbd>Right</kbd> | Collapse or expand a folder |
| <kbd>Enter</kbd> | Open the selected note |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Collapse every folder |

The tables above use the same `<kbd>` markup shown in the [[Markdown cheatsheet|cheatsheet]]. Suggestions for new keys go in [[Ideas]].
